finManager 
is a comprehensive personal finance tracking application that helps users manage their money effectively through several integrated features:
Core Features
1. Wallet Management

Track multiple wallets/accounts in one place
Monitor real-time balances across all accounts
Support for different currencies with IDR as the default

2. Transaction Tracking

Record both income and expenses with detailed categorization
Add descriptions and dates to each transaction
Filter and search transactions by type, date range, and category
Automatically update wallet balances when recording transactions

3. Budget System

Create budgets for specific expense categories
Set budget periods (typically monthly)
Track spending progress against budgets in real-time
Visual indicators show budget status (green for healthy, yellow for caution, red for over budget)
Get automatic suggestions to create budgets for categories with frequent expenses

4. Budget-Transaction Integration

Seamless connection between expenses and budgets
Expenses in budgeted categories automatically reduce the remaining budget
Immediate feedback when expenses affect budget limits
Warnings when transactions exceed budget limits

5. Financial Insights

View spending patterns by category
Track budget performance over time
See historical budget adherence

User Experience
The app features a clean, modern interface with an intuitive dashboard that provides an at-a-glance view of the user's financial situation. The responsive design works across different devices, allowing users to manage their finances anytime, anywhere.
Visually, the app uses color coding to quickly communicate financial status:

Green indicates positive balances, under-budget spending
Yellow shows caution zones as budgets approach their limits
Red highlights negative balances or over-budget situations

Technical Implementation
Finance Manager is built as a web application using:

PHP for the backend logic
MySQL database for data storage
HTML, CSS, and JavaScript for the frontend
Responsive design principles for cross-device compatibility

The database design ensures proper relationships between users, wallets, transactions, and budgets, maintaining data integrity while enabling complex queries for financial reporting.
Benefits

Financial Awareness: Helps users understand where their money goes
Budget Discipline: Encourages responsible spending by tracking against budget limits
Goal Setting: Supports financial goal planning through budget management
Expense Optimization: Identifies potential areas to reduce spending
Financial Organization: Keeps all financial information in one accessible place

Finance Manager aims to simplify personal finance management, helping users make informed decisions about their money and develop healthier financial habits over time.
